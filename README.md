## 按场景选：哪档够用，哪档纯属浪费

**学生练 Linux、跑爬虫、装数据库**：1 核 1G 是这条线的下限，能跑，但同时开 MySQL 加个 Node 服务就开始吃 swap。马尼拉或台湾年付 $24.99 适合纯练手，一年不到 180 元人民币。真要跑数据库又不想天天调优，直接上 Pay As You Go 的 2 核 2G，$5.60/月起。

**个人博客、作品集、小论坛**：1 核 1G／50GB SSD 装 WordPress 或 Typecho 够用，前提是别装十几个插件。年付比月付省下的钱，够你买一年域名。这类站点我更建议选洛杉矶 Global，$29.99/年，IP 干净、后续换机房也方便。

**跨境、代理中转、需要境外节点**：这条线看的是线路，不看核数。洛杉矶 Premium 走中国电信 CN2 GIA 和中国移动 CMIN2，是 LightLayer 全系里唯一针对中国大陆优化的选项，年付 $49.99。Standard 和 Global 是普通国际线路，国内访问绕路，晚高峰丢包概率高，省下的 $20 会在体验上还回去。

**Minecraft、Palworld 这类游戏服**：别看核数，看单核性能和内存。LightLayer 主力是 AMD EPYC 加 NVMe SSD，单核不弱，但 1G 内存开 MC 服会直接被 JVM 吃掉，至少 2G 起步。游戏服还有个现实问题：按年锁定的低价套餐，玩两周就腻了，退不了。这类需求用月付更稳。

**挂 Telegram bot、定时任务、小爬虫**：最低档就够，$24.99 年付那档基本是为此设计的。注意 HDD 和 SSD 的区别：官网公告里的圣何塞 SJ-Lite Cloud 是 1C1G／50G HDD，促销价 $2.45/月（原价 $4.9/月），存储介质是机械盘，跑 I/O 密集的爬虫会拖后腿。**这条公告同时说明一件事：LightLayer 的低价促销经常换配置、换机房，下单前一定看清当期页面写的是 SSD 还是 HDD。**

**32 核 32GB 的 Business 套餐**：$53.60/月。这个配置对上面所有场景都是浪费。它适合的是跑批量编译、渲染、或者十几个容器同时在线的团队。个人用户买它，等于给服务商的闲置资源付费。

## 谁不该买 LightLayer

**要国内备案建站的**：这是境外商家，国内机房业务不适用，你的站要放国内就得换服务商。

**要全管理服务的**：LightLayer 不提供托管型服务，面板、系统、安全、备份都得自己来。不会用 SSH 的话，这个价位段的所有无管理 VPS 都不适合你，该看的是共享主机或全管理 WordPress 托管。

**流量或带宽需求大的**：视频、CDN、大文件中转这类业务，1G 内存和共享带宽撑不住，年付锁一年更被动。

**需要确定性 SLA 赔偿的**：低价 VPS 的 SLA 更多是宣传口径，不是赔付合同。商业关键系统不该放在这个价位。

## 常见问题

**便宜 VPS 能建站吗？**
能。个人博客、作品集、低流量企业站，1 核 1G 加 50GB SSD 足够。撑不住的是高并发和大量插件，不是"便宜"本身。

**年付还是月付？**
LightLayer 这种退款范围窄的商家，先月付验证再年付。验证的内容就三件：能不能正常开机、你的网络连过去延迟多少、晚高峰会不会丢包。

**高峰期丢包怎么办？**
先确认你买的是哪条线路。洛杉矶 Premium 走 CN2 GIA 和 CMIN2，是这家唯一做国内优化的选项；Global 和 Standard 是普通国际线路，晚高峰波动属于预期内。真要稳定，加钱换线路，不是换配置。

**1G 内存够装 Docker 吗？**
能装，跑一两个轻量容器可以，跑数据库加应用就会吃紧。要用 Docker 编排多服务、跑 MySQL，直接选 Pay As You Go 的 2 核 2G 起步。

**续费会涨价吗？**
促销产品官网写明续费同价。常规套餐按官网现价续费，官方没有永久锁价承诺。年付前把当期页面价格截图留存，是唯一能做的准备。

**独立服务器和 GPU 服务器值得看吗？**
起步 $40/月（洛杉矶 E5-2660／8G／1T HDD）和更高。除非你要跑物理机业务或 RTX 4090 推理，否则跟"便宜 vps"这个需求无关。
